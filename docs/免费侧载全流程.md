# 回脉 免费侧载全流程（0 元 · Windows 无 Mac · 不越狱）

> 目标：不花 99 美元、不用 Mac、不越狱，把回脉作为一个**真正的独立 App** 装到你的 iPhone 上（从图标启动，没有 Safari 地址栏）。
> 原理：云端 Mac（Codemagic）负责编译出"无签名 ipa"，再用 Sideloadly 在你电脑上用**普通 Apple ID** 重新签名并安装。
>
> 全程分四个阶段，按顺序做即可。免费账号的硬限制：**签名 7 天有效（到期重签）、最多同时装 3 个 App、无推送和内购**。

## 阶段零：准备工具与账号（一次性）

### 1. 三个账号
- 一个普通 **Apple ID**（你 iPhone 上正在用的即可；若担心，可新注册一个备用 Apple ID）
- **GitHub** 账号（免费）：https://github.com/signup
- **Codemagic** 账号（免费额度，用 GitHub 登录即可）：https://codemagic.io

### 2. 电脑上安装 Sideloadly 和苹果驱动
- 下载 **Sideloadly Windows 版**：https://sideloadly.io ，下载后双击安装，一路下一步
- **Windows 必装的依赖（最容易卡住的一步）**：Sideloadly 要靠苹果的设备驱动才能连上手机，需要安装 **Apple 官网版的 iTunes 和 iCloud**，**不能用微软商店（Microsoft Store）版本**，商店版会导致连接失败
  - 官网版 iTunes：https://www.apple.com/itunes/download/win64
  - 官网版 iCloud：https://support.apple.com/zh-cn/HT208489
  - 如果你电脑里已经有商店版的 iTunes/iCloud，先在"设置 → 应用"里卸载，再装官网版
- 安装完成后重启一次电脑

## 阶段一：把代码上传到 GitHub

> 你的电脑没装 git，推荐用图形化的 GitHub Desktop（自带 git）。

1. 下载安装 **GitHub Desktop**：https://desktop.github.com
2. 打开后用 GitHub 账号登录
3. 菜单 **File → Add Local Repository**，选择文件夹 `D:\回脉`
   - 它会提示这不是 Git 仓库，点蓝色的 **"create a repository"**，名字保持默认，点 Create
4. 左下角在 **Summary** 随便填如 `init`，点 **Commit to main**
5. 点顶部 **Publish repository**，建议先勾选 **Keep this code private（设为私有）**，然后点 Publish
6. 完成后，登录 GitHub 网页就能看到这个项目

## 阶段二：在 Codemagic 云端编译出无签名 ipa

1. 打开 https://codemagic.io ，点 **Sign up with GitHub**，用 GitHub 登录并授权
2. 它会列出你的仓库，找到回脉项目，点 **Add application**
3. 它会自动识别仓库根目录的 `codemagic.yaml`，里面有两个工作流：
   - **回脉 iOS 免费无签名**（这次选这个）
   - 回脉 iOS 自动签名（以后付费再用）
4. 先把 `codemagic.yaml` 里 `your-email@example.com` 改成你自己的邮箱（在 GitHub 网页或 GitHub Desktop 里改，改完记得 Commit + Push）
5. 选中 **"回脉 iOS 免费无签名"**，点 **Start new build**
6. 等待约 10–15 分钟，可实时看云端日志；成功后：
   - 页面 **Artifacts** 里出现 `huimai-unsigned.ipa`，点下载
   - 你的邮箱也会收到下载链接
7. 把这个 ipa 存到电脑上一个好找的位置，如 `D:\回脉\huimai-unsigned.ipa`

> 这一步完全不需要付费苹果账号，因为我们没有在云端做签名。

## 阶段三：用 Sideloadly 签名并安装到 iPhone

1. 用 **数据线** 把 iPhone 连到电脑（首次建议用线，不要只用无线）
2. 解锁手机，若弹出 **"是否信任此电脑"**，点 **信任** 并输入锁屏密码
3. 打开 **Sideloadly**，左上角应能看到你的 iPhone 设备名；若看不到，检查 iTunes 是否为官网版、手机是否已信任
4. 把 `huimai-unsigned.ipa` **拖进 Sideloadly 窗口**（或点图标选择文件）
5. 在 **Apple account** 输入框填你的 **Apple ID 邮箱**
6. 点底部 **Start**
7. 弹出密码框时输入 **Apple ID 密码**：
   - 如果你的 Apple ID 开了双重认证（基本都开了），按提示输入手机上收到的 **6 位验证码**
   - 若提示需要专用密码，去 https://appleid.apple.com 登录，在"App 专用密码"处生成一个，粘贴进去
8. 等待进度条走完，出现 **Done** 即安装完成，此时手机桌面会出现"回脉"图标，**先别急着打开**

## 阶段四：手机上信任证书并开启开发者模式

### 1. 信任开发者描述文件
- 手机上打开 **设置 → 通用 → VPN与设备管理**
- 在"开发者 App"下找到你的 Apple ID 对应的描述文件，点进去，再点 **信任**，确认

### 2. 开启开发者模式（iOS 16 及以上必须）
- 打开 **设置 → 隐私与安全性**，滑到底部找到 **开发者模式**
- 打开开关，按提示 **重启手机**
- 重启后再次确认"开发者模式已打开"

### 3. 启动 App
- 回到桌面，点 **"回脉"图标**，它会以独立 App 形式全屏打开，没有 Safari 地址栏——这就是原生应用，不是网页

## 7 天后到期怎么办（重签）

- 免费 Apple ID 签的证书 **7 天过期**，过期后 App 点开会闪退或提示无法使用，**这是苹果的规则，不是出问题**
- 重签很简单：数据线连上电脑，打开 Sideloadly，重复"阶段三"的拖入 ipa → Start 即可，一两分钟搞定
- 重签**不会删除 App 内已有的数据**（只要 Bundle ID 没变）
- 想免去每周手动重签，可改用 **AltStore**（同一 WiFi 下自动后台刷新），或以后购买 99 美元账号获得 1 年有效期

## 常见问题速查

| 问题 | 解决办法 |
|---|---|
| Sideloadly 看不到设备 | 装官网版 iTunes/iCloud（非商店版），手机点"信任此电脑"，换原装或质量好的数据线 |
| 提示密码错误 / 验证失败 | 确认 Apple ID 密码正确；双重认证填 6 位验证码；必要时用 App 专用密码 |
| 装上后打开提示"未受信任开发者" | 去 设置→通用→VPN与设备管理 里信任描述文件 |
| 提示需要开发者模式 | 设置→隐私与安全性→开发者模式，打开并重启 |
| 提示 "Maximum App ID limit" | 免费账号每周约 10 个 App ID 上限，等下周重置，或换一个 Apple ID |
| App 里视频/接口加载不出来 | 确认手机和电脑连同一 WiFi、电脑后端 9090 在运行、`.env.production` 的 IP 与当前电脑 IP 一致（用 ipconfig 查） |
| 同时装第 4 个 App 失败 | 免费账号最多 3 个活跃 App，先删掉一个不常用的 |
